# EC2 (Elastic Compute Cloud)

## Hiểu nhanh
Giống **thuê một chiếc máy tính ở xa** theo giờ. Bạn chọn cấu hình (CPU, RAM), cài hệ điều hành, rồi SSH vào dùng như máy của mình.

## Cần nhớ
- **Instance**: một máy ảo. **Instance type**: cấu hình, vd `t3.small` (2 vCPU, 2 GB RAM).
- **AMI**: "bản cài sẵn" hệ điều hành (Ubuntu, Amazon Linux...).
- **EBS**: ổ đĩa gắn vào máy (vd 30 GB gp3). Terminate máy thì ổ mặc định bị xóa theo.
- **Key pair**: khóa SSH (file `.pem`) để đăng nhập. Mất file là mất đường vào.
- **Security Group**: tường lửa của máy (xem [03](03-vpc-security-group.md)).
- **IP public** đổi mỗi lần stop/start. Muốn cố định dùng **Elastic IP**.
- **Trạng thái**: `running` (tính tiền) / `stopped` (chỉ tính ổ đĩa) / `terminated` (xóa hẳn).
- **IAM role (instance profile)**: cho máy quyền gọi AWS mà không cần lưu key.

## Lệnh hay dùng
```bash
aws ec2 describe-instances --query 'Reservations[].Instances[].[InstanceId,State.Name,PublicIpAddress,Tags[?Key==`Name`]|[0].Value]' --output table
aws ec2 stop-instances      --instance-ids <i-xxx>
aws ec2 start-instances     --instance-ids <i-xxx>
aws ec2 terminate-instances --instance-ids <i-xxx>      # xóa hẳn, không hoàn tác

ssh -i ~/.ssh/<key>.pem ubuntu@<ip-public>              # Ubuntu: user ubuntu; Amazon Linux: ec2-user
```

## Chi phí & lưu ý
- Tính tiền theo giờ khi `running`. Học xong nhớ **stop** hoặc terminate.
- **Elastic IP** không gắn vào máy đang chạy vẫn bị tính tiền; release khi không dùng.
- File `.pem` phải `chmod 400` (Linux/Mac), không commit lên Git.
- SSH chỉ mở cho IP của mình, đừng mở `0.0.0.0/0` cổng 22.
