# S3 (Simple Storage Service)

## Hiểu nhanh
Giống **Google Drive cho ứng dụng**: ném file vào, lấy ra bằng đường dẫn, dung lượng gần như không giới hạn. Không phải ổ đĩa để cài chương trình.

## Cần nhớ
- **Bucket**: "thư mục gốc", tên phải **duy nhất toàn cầu**, thuộc một region.
- **Object**: file + metadata, định danh bằng **key** (vd `anh/2026/avatar.png`). Không có thư mục thật, `/` chỉ là quy ước đặt tên.
- **Storage class**: Standard (hay truy cập) -> Standard-IA / Glacier (rẻ hơn, truy cập ít).
- **Block Public Access**: để **bật**. Chỉ mở public khi thực sự cần (vd host web tĩnh).
- **Versioning**: giữ các phiên bản cũ, xóa nhầm vẫn khôi phục được.
- **Lifecycle rule**: tự chuyển hoặc xóa file cũ để tiết kiệm.
- **Presigned URL**: link tạm thời cho người ngoài tải/up file mà không cần quyền AWS.

## Lệnh hay dùng
```bash
aws s3 ls                                   # liệt kê bucket
aws s3 mb s3://ten-bucket-duy-nhat          # tạo bucket
aws s3 cp file.txt s3://ten-bucket/         # upload
aws s3 cp s3://ten-bucket/file.txt .        # download
aws s3 sync ./thu-muc s3://ten-bucket/thu-muc   # đồng bộ cả thư mục
aws s3 rm s3://ten-bucket/file.txt
aws s3 rb s3://ten-bucket --force           # xóa bucket + toàn bộ nội dung (cẩn thận!)
aws s3 presign s3://ten-bucket/file.txt --expires-in 3600
```

## Chi phí & lưu ý
- Tính theo dung lượng lưu + số request + dữ liệu đi ra internet.
- Bucket public nhầm là nguồn lộ dữ liệu phổ biến nhất. Kiểm tra Block Public Access.
- `sync --delete` và `rb --force` xóa thật, đọc kỹ trước khi chạy.
